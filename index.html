Proyek

Sistem Chatbot GAD-7

Integrasi Sistem Detail
Sistem Chatbot GAD-7 untuk Skrining Kecemasan
Tentang Proyek

Proyek tugas akhir berupa sistem chatbot berbasis WhatsApp untuk skrining awal tingkat kecemasan menggunakan instrumen GAD-7. Sistem mengintegrasikan WhatsApp API dengan backend Laravel dan database MySQL untuk memproses jawaban, menghitung skor, serta menyajikan hasil skrining. Sistem juga menyediakan dashboard bagi Guru BK untuk memantau hasil skrining siswa. Hasil skrining bukan diagnosis medis dan tidak menggantikan konsultasi profesional.

Peran dan Implementasi
  • Mengintegrasikan WhatsApp API, webhook, dan REST API.
  • Mengimplementasikan perhitungan skor GAD-7 berbasis aturan.
  • Mengelola data skrining menggunakan Laravel dan MySQL.
  • Mendeploy aplikasi pada VPS Ubuntu dengan Nginx.
  • Melakukan pengujian integrasi, response time, dan beban sistem.
